# Trade The Future — การใช้งานฉบับเว็บ

## เปิดโปรเจกต์

- พัฒนา: `npm run dev`
- ตรวจ: `npm run lint`, `npm test`, `npm run build`
- เปิด build: `npm run start`
- การทดสอบ quiz ใช้ Node.js ที่รองรับ TypeScript type stripping (ตรวจด้วย Node 24)

## จุดแก้ไขหลัก

- `app/page.tsx`: โครง 15 ส่วนและข้อความบนหน้า
- `app/content.ts`: ลิงก์ LINE/AlgoPrime, บทเรียน, FAQ, คำถามและผล quiz
- `app/components/interactive.tsx`: quiz, เมนูมือถือ และตัวเลือกระยะเวลาแพ็กเกจ
- `app/components/art.tsx`: ภาพประกอบกราฟ ตัวละคร และสัญลักษณ์ SVG
- `app/capital-calculator.ts` และ `app/components/capital-calculator.tsx`: สูตรทุนและส่วนคำนวณเป้ากำไรที่วางถัดจาก Quiz
- `app/globals.css`: สี ฟอนต์ ระยะห่าง และขนาดหน้าจอ
- `app/layout.tsx`: ฟอนต์ metadata และ noindex ของฉบับร่าง

## สิ่งที่พร้อมใช้

หน้าไทยดำ–ทอง มีหลักสูตร สิทธิ์ตามที่ยืนยัน FAQ แบบเปิดปิดและคีย์บอร์ด เมนูมือถือ ปุ่ม LINE/AlgoPrime และ quiz 5 ข้อที่แสดงผลได้ 4 ตัวละคร มีเป้าหมายจากข้อ 5 คะแนนเสมอ ปัญหารอง ย้อนกลับแก้คำตอบ และเริ่มใหม่โดยไม่เก็บข้อมูลติดต่อ

เพิ่มเครื่องคำนวณทุนที่ `#calculator`: กรอกเป้ากำไร USD เลือกความเสี่ยง 0.5/1/2/3% เริ่มต้น 3% ล็อก TP 1,000 จุดและ SL 500 จุด คำนวณหนึ่งแผน ไม่ใช่ความเสี่ยงรวมหลายออร์เดอร์รายวัน มีตารางเทียบ สูตร และขอบเขตที่ไม่รวมค่าธรรมเนียม/slippage/margin ดูรายละเอียดใน calculator-spec.md

## สิ่งที่ยังรอ

Hero/VSL และรีวิวจริง ลิงก์ซื้อคลาส 990 โดยตรง ชื่อ/ภาพผู้ก่อตั้งและโลโก้ทางการ สื่อบนหน้าระหว่างนี้เป็น SVG ที่วาดขึ้นและข้อความแนะนำชั่วคราว กราฟระบุว่าเป็นภาพประกอบ ไม่ใช่ผลการเทรด

ไม่มีระบบชำระเงินหรือจัดการสมาชิกในเว็บนี้ ปุ่มพาไป LINE หรือ AlgoPrime ตามลิงก์ที่ให้ ไม่ได้เชื่อม Whop/Discord และไม่ได้เผยแพร่ขึ้นอินเทอร์เน็ต

## ตรวจแล้ว

- Production build และ TypeScript ผ่าน
- ESLint ผ่าน
- ตรวจ 1,024 ชุดคำตอบ: เป้าหมายข้อ 5 ไม่เปลี่ยนตัวละคร พร้อมตัวอย่างผลทั้ง 4 แบบ คะแนนเสมอ และคำตอบไม่ครบ
- ทดสอบ Chrome: quiz ครบทุกผลลัพธ์ เปลี่ยนเป้าหมาย ย้อนกลับ เริ่มใหม่ ราคา 2 ระยะ เมนูมือถือ FAQ ผ่านคีย์บอร์ด และลิงก์ภายใน
- ไม่พบหน้าแนวนอนล้นที่ความกว้าง 375, 390, 768, 1024 และ 1440 พิกเซล; ไม่พบ browser runtime errors ระหว่างทดสอบ
- ตรวจภาพจริงของ Hero, Quiz, ผลลัพธ์ และส่วนเครื่องมือบน desktop/mobile
- ไม่ได้กดสมัคร ซื้อ หรือส่งข้อความไปยังบริการภายนอก
- เครื่องคำนวณ: unit tests สำหรับผลตัวอย่าง การเปลี่ยนความเสี่ยง ทศนิยม การปัดทุนขึ้นเป็นเซนต์ และค่าผิด; ทดสอบ browser สำหรับแก้เป้ากำไร/ความเสี่ยง ตารางเทียบ เคลียร์ผลเมื่อกรอกผิด เปิดสูตรด้วยคีย์บอร์ด และค่าสูงสุดที่ 320/375/390/768/1024/1440 พิกเซล ไม่พบหน้าแนวนอนล้นหรือ runtime error
