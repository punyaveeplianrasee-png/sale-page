# ADR 0001 — สัมภาษณ์ทีละประเด็นและบันทึกข้อสรุป

- วันที่: 2026-09-17
- สถานะ: ยอมรับโดยเจ้าของโปรเจกต์

## บริบท

เจ้าของเรียกใช้ grill-with-docs เพื่อพัฒนาแผนหน้า Trade The Future โดย skill อ้างถึง grilling และ domain-modeling ซึ่งไม่พบในสภาพแวดล้อมนี้ และไม่มีเครื่องมือ Skill ให้เรียก

## การตัดสินใจ

เจ้าของอนุญาตให้ใช้วิธีสัมภาษณ์ทีละประเด็น พร้อมบันทึกข้อสรุปและคำศัพท์ในโปรเจกต์แทน เริ่มที่ลูกค้าหลัก แล้วจึงไล่ความสัมพันธ์ของสินค้า quiz เนื้อหา และการซื้อ

## วิธีบันทึก

- เก็บบรีฟและคำถามเปิดใน docs/sales-page-brief.md
- เก็บคำศัพท์และประเด็นที่ต้องยืนยันใน docs/glossary.md
- บันทึกการตัดสินใจสำคัญเพิ่มเติมใน docs/decisions/ เมื่อมีข้อสรุปจริง
- แยกข้อเสนอของผู้ช่วยจากข้อเท็จจริงที่เจ้าของให้ และไม่ใช้ความเงียบเป็นการยืนยัน

## ผลที่ตามมา

การพัฒนาจะอ้างอิงข้อมูลที่ตรวจสอบย้อนกลับได้ ประเด็นที่ยังเปิดจะไม่ถูกเขียนเป็นสิทธิ์สินค้า ผลลัพธ์ผู้เรียน หรือเงื่อนไขการซื้อที่ยืนยันแล้ว การอนุญาตครั้งนี้เป็นการอนุญาตวิธีทำงาน ไม่ใช่การยอมรับข้อเสนอด้านกลุ่มลูกค้า ราคาเพิ่มเติม หรือ framework ที่ยังไม่หารือ
