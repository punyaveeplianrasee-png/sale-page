# ADR 0004 — ทดลอง Membership โดยไม่ต้องใช้ broker และต่อสิทธิ์แบบมีเงื่อนไข

- วันที่: 2026-09-17
- สถานะ: บันทึกตามคำยืนยันของเจ้าของ

## ข้อสรุป

- ผู้ซื้อคลาส 990 ทดลอง Membership ได้ 7 วันโดยไม่ต้องเปิดบัญชีหรือฝากเงินกับ Connext
- เจ้าของยืนยันเพิ่มเติมว่าช่วงทดลองดูทุกอย่างใน Membership ได้ แต่ไม่สามารถพิมพ์ข้อความใด ๆ ได้ ซึ่งเป็นข้อแตกต่างจากสมาชิกปกติ สิทธิ์ถามใน Student ระหว่างเรียนยังเป็นไปตามข้อมูลก่อนหน้า
- กิจกรรมที่ยืนยันเพิ่มเติม: Zone ทุกวัน, Live เทรด 06:00–24:00, Special Class GSS/TTS เดือนละ 2 เสาร์ และห้อง Signal ที่มาสเตอร์ผู้ไลฟ์ส่งแผน
- ยืนยันตารางเพิ่มเติม: Zone และ Live ให้บริการวันจันทร์–ศุกร์ตามเวลาไทย ผู้ทดลองดู Special Class ย้อนหลังได้ จึงดูเนื้อหาได้แม้ไม่ตรงวันสอนสดในช่วงทดลอง
- คลาสเป็นสินค้าขั้นแรกสำหรับเสนอ deposit, tools และ TMC class ต่อภายหลัง
- การต่อ Membership ผ่าน Connext มีเงื่อนไขพอร์ตขั้นต่ำ $500 และเทรดขั้นต่ำเดือนละ 1 lot
- หากไม่ได้ใช้ Connext และไม่มีการเทรด 1 เดือน จะถูกถอน role Membership และไม่สามารถเข้าห้อง Member ได้

## ผลต่อหน้า sale page

แยกสิทธิ์ทดลองที่รวมในราคา 990 ออกจากการต่อสิทธิ์หลังทดลอง ข้อความ Membership หลังทดลองต้องระบุว่ามีเงื่อนไข หลีกเลี่ยงคำว่า «ถาวร» ที่สื่อว่าไม่มีข้อกำหนดต่อเนื่อง เงินในพอร์ต broker ไม่ใช่ราคาคลาสหรือราคาเครื่องมือ และเงื่อนไขปริมาณเทรดไม่ใช่คำแนะนำให้ผู้เรียนเร่งเทรด

## ประเด็นเปิด

- พอร์ตขั้นต่ำ $500 หมายถึง balance หรือ equity และตรวจเมื่อใด
- วิธีนับ 1 lot และรอบเดือน รวมถึงกรณีเทรดไม่ถึงเกณฑ์แต่ไม่ใช่ศูนย์
- วิธีตรวจสิทธิ์ การเชื่อมบัญชี และวิธีคืน role
- รายการกิจกรรม ความต่างด้านการพิมพ์ วันให้บริการ เวลาไทย และสิทธิ์ย้อนหลัง Special Class ยืนยันแล้ว; ยังไม่ระบุเสาร์ใดและเวลาใดของคลาสสด

เงื่อนไขข้างต้นเป็นข้อมูลบริการจากเจ้าของ ไม่ได้อ้างว่าเป็นข้อกำหนดที่ตรวจสอบจาก Connext
