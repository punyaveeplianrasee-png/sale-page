# ADR 0005 — ช่องทางสอบถามและซื้อสินค้าต่อยอด

- วันที่: 2026-09-17
- สถานะ: ช่องทางยืนยันโดยเจ้าของ; การจัดวางเป็นการตีความคำตอบเพื่อดำเนินงาน

## บริบทและคำตอบ

ผู้ช่วยเสนอทั้งการแนะนำเครื่องมือ/TMC เป็นขั้นต่อไป และการแสดงแพ็กเกจกับราคาช่วงท้ายพร้อมปุ่มสอบถาม เจ้าของตอบรับทั้งสองข้อ ระบุ LINE OA https://lin.ee/uyUcmIM และขออีกปุ่มไปเว็บไซต์หลักซึ่งซื้อสินค้าได้เช่นกัน

## การนำไปใช้

- รักษาคลาส 990 เป็นข้อเสนอหลักตาม ADR 0002
- รวมสองส่วนเป็นการแนะนำเส้นทางต่อยอดก่อน แล้ววางแพ็กเกจและช่องทางสอบถาม/ซื้อช่วงท้าย
- ปุ่มสอบถามใช้ LINE OA ที่ให้มาโดยตรง
- ปุ่มซื้อบนเว็บไซต์หลักต้องรอ URL จริง ไม่เดาปลายทาง
- คำตอบเพิ่มเติม: เจ้าของให้ข้าม URL เว็บไซต์ไปก่อนและจะเพิ่มภายหลัง พร้อมยืนยันว่าใช้ LINE OA ได้เลย จึงเดินหน้าส่วนอื่นโดยไม่ขอลิงก์ซ้ำ
- แนวทางดำเนินงาน: ใช้ปุ่มสอบถามผ่าน LINE ที่พร้อมใช้งาน และเก็บปุ่มเว็บไซต์ไว้ในแผนจนมี URL จริง ไม่ทำลิงก์หลอกหรือปุ่มซื้อที่ไม่มีปลายทาง
- อัปเดตล่าสุด: เจ้าของให้ https://algoprime.co/sign-up/?ref=015240 สำหรับสมัครและซื้อในบริบทเครื่องมือ จึงเพิ่มปุ่ม «สมัครและซื้อเครื่องมือผ่าน AlgoPrime» พร้อมคง ref=015240; ลิงก์ซื้อคลาส 990 ยังคงพักไว้ ไม่ขยายการใช้ลิงก์นี้ไปยังคลาสโดยไม่มีข้อมูล
- เครื่องมือเว็บเปิดลิงก์ AlgoPrime ไม่สำเร็จ ยังไม่ได้ตรวจหน้าปลายทางหรือกระบวนการซื้อ การใช้ URL อ้างอิงคำยืนยันเจ้าของ

## ประเด็นเปิด

- URL เว็บไซต์หลักและหน้าซื้อคลาส 990: พักตามคำสั่งเจ้าของ เพื่อเพิ่มภายหลัง
- ยืนยันเพิ่มเติมแล้วว่าแพ็กเกจเครื่องมือเข้า TMC ได้เลย และทั้งสองแพ็กเกจสิทธิ์เหมือนกัน ต่างเฉพาะระยะเวลา ดู ADR 0006; รายละเอียดบริการยังเปิด

การบันทึกลิงก์เป็นการเตรียมปุ่มบนหน้า ไม่ได้เป็นคำขอให้ส่งข้อความผ่าน LINE
