# เครื่องคำนวณทุนจากเป้าหมาย — ขอบเขตและสูตร

สถานะ: พัฒนาเครื่องคำนวณบนหน้าถัดจาก Quiz แล้ว ตามรายละเอียดด้านล่าง

## คำขอที่ยืนยันแล้ว

- เพิ่มเป็นส่วนโต้ตอบใน sales page ธีมดำ–ทอง
- ให้ผู้เข้าชมกรอกกำไรที่ต้องการต่อวัน และเลือกเปอร์เซ็นต์ความเสี่ยงที่รับได้
- ล็อกระยะทำกำไรในแบบจำลองไว้ที่ 1,000 จุด
- แสดงทุนที่คำนวณได้จากสมมติฐาน ไม่ใช้ชื่อผลลัพธ์ที่รับประกันว่ามีทุนนี้แล้วจะได้กำไรตามเป้าจริง

## ประเด็นที่ถามเจ้าของแล้ว

1. ความเสี่ยงหมายถึงขาดทุนสูงสุดต่อวันหรือต่อออร์เดอร์ และระยะ Stop Loss คงที่หรือให้ผู้ใช้กรอก
2. เป้ากำไรแสดงเป็น USD หรือบาท และนิยาม 1,000 จุดในระบบเป็นอย่างไร

เจ้าของตอบว่าใช้ความเสี่ยง 3% และ SL 500 จุด พร้อมตอบรับนิยาม 1,000 จุด = ราคาทองขยับ $10 ผู้ช่วยแจ้งใช้ USD เป็นหน่วย ความเสี่ยง 3% เป็นค่าเริ่มต้นที่เลือกปรับได้ตามคำขอแรก และระบุขอบเขตเป็นแบบจำลองหนึ่งแผน/การถึง SL หนึ่งครั้ง เนื่องจากไม่มีข้อมูลการขาดทุนรวมหลายออร์เดอร์ต่อวัน ไม่เรียก 3% นี้ว่าเพดานขาดทุนรวมรายวัน

ตัวเลือกความเสี่ยงสำหรับสำรวจ: 0.5%, 1%, 2%, 3% โดยไม่มีตัวเลือกใดระบุว่าเหมาะสมหรือแนะนำให้ผู้ใช้ เป้ากำไรเริ่มต้น $100 เป็นตัวอย่างแก้ไขได้ ระยะกำไรและ SL ล็อก 1,000/500 จุด

## สูตรที่ใช้เตรียมการ

กำหนด P = เป้ากำไรเป็นเงิน, T = ระยะทำกำไร 1,000 จุด, S = ระยะ Stop Loss ในหน่วยจุดเดียวกัน, r = เปอร์เซ็นต์ความเสี่ยง / 100

สำหรับสถานการณ์ขนาดสถานะเท่ากันและการตัดขาดทุนหนึ่งครั้ง:

- ผลขาดทุนเมื่อถึง Stop Loss = P × S / T
- ทุนตามสมมติฐานความเสี่ยง = (P × S / T) / r
- อัตราระยะทำกำไรต่อระยะ Stop Loss = T / S

หากความเสี่ยงเป็นงบขาดทุนรวมต่อวัน ต้องกำหนดจำนวนครั้ง/ระยะขาดทุนรวมที่แบบจำลองรองรับด้วย ไม่ใช้ความเสี่ยงต่อออร์เดอร์แทนความเสี่ยงรวมรายวันโดยไม่บอก

ค่าตั้งต้นของหน้า: P = $100, S = 500, T = 1,000, r = 3% → ขาดทุนตาม SL = $50 → ทุนตามสมมติฐานประมาณ $1,666.67 (ปัดทุนขึ้นเป็นเซนต์) หากเลือก 1% จะได้ทุน $5,000 สำหรับเป้าเดิม

การคำนวณทุนด้วยอัตราส่วนจุดนี้ไม่ต้องแปลงมูลค่าต่อจุด เพราะใช้หน่วยจุดเดียวกันทั้งสองด้าน หากเพิ่ม lot ในผลลัพธ์จึงต้องมีนิยาม point และ contract size ของสัญญาจริง

## การนำเสนอ

- วางต่อจาก quiz ให้ผู้สนใจสำรวจเป้าหมาย ก่อนอ่านวิธีเรียนและ roadmap
- ช่องกรอกเป้ากำไร ความเสี่ยง และระยะขาดทุนที่ตกลงกัน
- แสดงเป้าระยะ 1,000 จุดแบบแก้ไขไม่ได้
- แสดงทุนตามสมมติฐาน ผลขาดทุนตามระยะ SL และสูตรให้ตรวจที่มาได้
- ช่องกรอกเป้ากำไรรับ $0.01–$1,000,000; ไม่คำนวณเมื่อค่าหาย เป็นศูนย์ ติดลบ ไม่ใช่ตัวเลข หรืออยู่นอกช่วง ผลเก่าต้องหายแทนที่ด้วยสถานะรอข้อมูล
- ระบุว่าไม่รวมค่าธรรมเนียม spread/slippage และไม่ได้คำนวณ margin หรือโอกาสทำกำไรถึงเป้า
- ไม่เชื่อมผลลัพธ์ไปแนะนำการฝาก Connext อัตโนมัติ ใช้ CTA เรียนรู้การบริหารเงินในคลาสแทน
